# 防撤回（LSPosed 微信模块）



本项目是一个面向 Android/LSPosed 环境的微信本地客户端模块示例，当前发布包针对 **微信 8.0.79（3200）**。



## 功能



- 在微信本地显示逻辑中拦截特定撤回处理，尽量保留已收到的消息内容。
- 
- 可显示“对方尝试撤回一条消息（已阻止）”提示。
- 
- 可选显示每条聊天消息的详细时间（`HH:mm:ss`）。
- 
- 设置页提供防撤回、详细时间和 Hook 状态相关选项。
- 


这些功能只影响当前设备上的本地显示，不会改变微信服务器端消息状态，也不会阻止对方或其他设备正常撤回。



## 环境要求



- 已解锁 Bootloader 的 Android 设备，并已获得 Root 权限。
- 
- 已安装 LSPosed（Modern API）或兼容的 Xposed 框架。
- 
- 微信包名为 `com.tencent.mm`，建议使用微信 **8.0.79（3200）**。
- 
- 需要在 LSPosed 中启用模块，并将作用域限定为微信；启用后强制停止并重新打开微信。
- 


## 安装与启用



1. 下载 `fangchehui-8.0.79-3200.apk` 并安装。
2. 
2. 打开 LSPosed，进入“模块”，勾选“防撤回”。
3. 
3. 在作用域中仅勾选微信 `com.tencent.mm`。
4. 
4. 强制停止微信后重新启动。
5. 
5. 从 LSPosed 的模块详情进入设置页，按需打开“防撤回”和“显示详细发送时间”。
6. 
6. 可在设置页查看 Hook 状态；若状态未成功，先确认微信版本、作用域和进程重启情况。
7.
